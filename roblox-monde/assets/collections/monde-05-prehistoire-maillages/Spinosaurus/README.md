# Spinosaure

18 pièces avec RigRoot, 4 698 triangles. Museau allongé, grande voile dorsale, queue haute et griffes. Le modèle se nomme Spinosaurus.

Importer Spinosaurus-Import3D-Motor6D.fbx sans fusionner les maillages. Insérer Spinosaurus-rig-template.rbxmx. Sélectionner les deux modèles en mode édition puis exécuter Assembler-Spinosaurus.luau. Les Motor6D et les KeyframeSequence sont dans le gabarit, pas dans le FBX seul. Les originaux sont conservés.

Animations : Idle, Walk (bipède), Attack, Bite. Lire avec gain 1, vitesse de référence 1. Seules les deux pattes arrière portent l'animal ; les bras ne touchent pas le sol. Rapports joints pour géométrie, structure, symétrie, contacts et appuis.

Insérer SpinosaurusEgg.rbxmx pour l'œuf assorti sans nid (78 pièces statiques, racine comprise). Son FBX est optionnel. Aucun script incorporé.

PNG et GIF montrent les vrais maillages sous les transformations des clips. Les GIF bouclent pour l'aperçu seulement : Attack et Bite livrés ne bouclent pas et ont chacun un seul repère Impact.

Import final et rendu dans Studio encore à valider. Fabrication locale gratuite, jeu inchangé, aucun crédit Meshy. Sources livrées sur la branche claude/exciting-gauss-ggwcwm. Voir le README commun.
