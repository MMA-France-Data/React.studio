# T-rex — boss

Version 2, retouchée le 9 octobre 2026 : 17 pièces avec RigRoot, 4 686 triangles. Museau plus long à pans plats, arrière du crâne élargi, regard oblique sous une arcade osseuse, poitrine et cuisses renforcées, pieds plus larges. Deux petits bras à deux doigts, longue queue et robe arc-en-ciel de boss conservés. Le modèle se nomme Trex ; T-rex est son nom d'affichage.

La structure, les pivots des 16 Motor6D et les quatre clips d'origine sont conservés. Les C0/C1 sont retargetés aux nouvelles limites des maillages. L'œuf est inchangé. L'ancien modèle est archivé localement pour comparaison.

Importer Trex-Import3D-Motor6D.fbx sans fusionner les maillages. Insérer Trex-rig-template.rbxmx. Sélectionner les deux modèles en mode édition puis exécuter Assembler-Trex.luau. Les Motor6D et les KeyframeSequence sont dans le gabarit, pas dans le FBX seul. Les originaux sont conservés.

Animations : Idle, Walk (bipède lourd), Attack (rugissement et morsure écrasante), Bite. Lire avec gain 1, vitesse de référence 1. Seules les deux pattes arrière portent le boss. Rapports joints pour géométrie, structure, symétrie, contacts et appuis.

Insérer TrexEgg.rbxmx pour l'œuf arc-en-ciel sans nid (56 pièces statiques, racine comprise). Son FBX est optionnel. Aucun script incorporé.

PNG et GIF montrent les vrais maillages sous les transformations des clips. Les GIF bouclent pour l'aperçu seulement : Attack et Bite livrés ne bouclent pas et ont chacun un seul repère Impact.

Import final et rendu dans Studio encore à valider. Fabrication locale gratuite, jeu inchangé, aucun crédit Meshy. Sources livrées sur la branche claude/exciting-gauss-ggwcwm. Voir le README commun.
