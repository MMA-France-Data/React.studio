# Vélociraptor — premier animal de la Préhistoire

17 pièces avec RigRoot, 4 712 triangles. Modèle vert et crème avec yeux noirs intégrés, griffes relevées, petits bras non porteurs et longue queue. Le modèle se nomme Velociraptor.

Importer Velociraptor-Import3D-Motor6D.fbx sans fusionner les maillages. Insérer Velociraptor-rig-template.rbxmx. Sélectionner les deux modèles en mode édition puis exécuter Assembler-Velociraptor.luau. Les Motor6D et les KeyframeSequence sont dans le gabarit, pas dans le FBX seul. Les originaux sont conservés.

Animations : Idle, Walk (bipède), Attack et Bite. Lire avec gain 1 et vitesse de référence 1, pas le gain global 2.6 des anciens animaux. Genoux et chevilles compensent les appuis. Les petits bras restent au-dessus du sol. Les rapports joints couvrent géométrie réimportée, structure, symétrie, contacts et marche.

Insérer VelociraptorEgg.rbxmx pour l'œuf assorti sans nid (81 pièces statiques, racine comprise). Son FBX est optionnel. Aucun script incorporé.

Les PNG et GIF montrent les vrais maillages sous les transformations des clips livrés. Les GIF bouclent pour l'aperçu seulement : Attack et Bite livrés ne bouclent pas et ont chacun un seul repère Impact.

Import et rendu dans Studio encore à valider. Fabrication locale gratuite, aucun crédit Meshy, jeu inchangé. Sources livrées sur la branche claude/exciting-gauss-ggwcwm. Voir le README commun pour l'import détaillé.
