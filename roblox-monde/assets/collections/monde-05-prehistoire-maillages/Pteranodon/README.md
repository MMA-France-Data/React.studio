# Ptéranodon

18 pièces avec RigRoot, 4 560 triangles. Ailes en trois segments par côté, bec articulé et crête intégrée. Le modèle se nomme Pteranodon.

Importer Pteranodon-Import3D-Motor6D.fbx sans fusionner les maillages. Insérer Pteranodon-rig-template.rbxmx. Sélectionner les deux modèles en mode édition puis exécuter Assembler-Pteranodon.luau. Les Motor6D et les KeyframeSequence sont dans le gabarit, pas dans le FBX seul. Les originaux sont conservés.

Animations : Idle, Walk (vol), Attack (piqué et coup de bec), Bite. Lire avec gain 1, vitesse de référence 1. Les ailes ne sont pas des pattes porteuses. Le placement aérien, la trajectoire et les collisions devront être intégrés séparément dans le jeu. À l'échelle livrée, prévoir environ 1,75 unité entre RigRoot et le sol pour dégager le bas des ailes ; ajuster proportionnellement à l'échelle et au terrain.

Insérer PteranodonEgg.rbxmx pour l'œuf assorti sans nid (72 pièces statiques, racine comprise). Son FBX est optionnel. Aucun script incorporé.

PNG et GIF montrent les vrais maillages sous les transformations des clips. Les GIF bouclent pour l'aperçu seulement : Attack et Bite livrés ne bouclent pas et ont chacun un seul repère Impact. Rapports joints pour géométrie, structure, symétrie, contacts et vol.

Import final et rendu dans Studio encore à valider. Fabrication locale gratuite, jeu inchangé, aucun crédit Meshy. Sources livrées sur la branche claude/exciting-gauss-ggwcwm. Voir le README commun.
