# Tricératops

19 pièces avec RigRoot, 4 698 triangles. Corps massif, trois cornes et collerette osseuse intégrée. Le modèle se nomme Triceratops.

Importer Triceratops-Import3D-Motor6D.fbx sans fusionner les maillages. Insérer Triceratops-rig-template.rbxmx. Sélectionner les deux modèles en mode édition puis exécuter Assembler-Triceratops.luau. Les Motor6D et les KeyframeSequence sont dans le gabarit, pas dans le FBX seul. Les originaux sont conservés.

Animations : Idle, Walk (quatre appuis), Attack (charge aux trois cornes), Bite (coup de bec). Lire avec gain 1, vitesse de référence 1. Genoux et chevilles compensent la marche. Rapports joints pour géométrie, structure, symétrie, contacts et appuis.

Insérer TriceratopsEgg.rbxmx pour l'œuf assorti sans nid (77 pièces statiques, racine comprise). Son FBX est optionnel. Aucun script incorporé.

PNG et GIF montrent les vrais maillages sous les transformations des clips. Les GIF bouclent pour l'aperçu seulement : Attack et Bite livrés ne bouclent pas et ont chacun un seul repère Impact.

Import final et rendu dans Studio encore à valider. Fabrication locale gratuite, jeu inchangé, aucun crédit Meshy. Sources livrées sur la branche claude/exciting-gauss-ggwcwm. Voir le README commun.
