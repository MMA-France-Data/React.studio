# Animations et effets de combat — livraison complète

Le pack complet est dans [roblox-monde/assets/combat](../../../roblox-monde/assets/combat/README.md).

Il contient les 36 animaux des salles 1 à 6 avec attaques/morsures, le cabré du cheval, les deux coupes circulaires du personnage, six formes d'épée, effets, aperçus et galeries de test.

Les collections originales de ce dossier restent inchangées. Le pack est à intégrer de façon ciblée dans MONDE : lire le guide, ne pas publier la copie de référence à la place du jeu actuel. Les vérifications hors Studio sont fournies ; le test d'exécution dans Studio reste à faire.
