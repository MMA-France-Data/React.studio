# Modèles visuels gratuits — SURVIVE!

Les fichiers `.rbxmx` contiennent uniquement de la géométrie et des composants
visuels reconstruits depuis les modèles gratuits du Creator Store. Aucun script,
remote, weld ou comportement de leurs auteurs n'est intégré.

| Fichier | Source | Auteur | Usage |
| --- | --- | --- | --- |
| BenchPress.rbxmx | [Bench Station 1](https://create.roblox.com/store/asset/18999544867/Bench-Station-1) | yaybravl | Banc de musculation |
| Treadmill.rbxmx | [cardio](https://create.roblox.com/store/asset/85059126195767/cardio) | z8ir | Deux tapis de course ; les autres machines de ce pack ne sont pas incluses |
| Trampoline.rbxmx | [Trampoline](https://create.roblox.com/store/asset/13052221356/Trampoline) | Campo925029 | Cadre, toile et pieds du trampoline |
| Meteor.rbxmx | [Realistic Meteor](https://create.roblox.com/store/asset/2847767720/Realistic-Meteor) | SionixKev | Météorites |
| Rock.rbxmx | Même modèle Realistic Meteor | SionixKev | Rochers décoratifs sous certaines plateformes de lave |

Gratuité vérifiée le 5 octobre 2026. `PROVENANCE.json` conserve les identifiants,
les liens, les dimensions, le nombre de pièces et les empreintes des fichiers.

Les modèles sont inclus dans ServerStorage à la construction du jeu. Aucun
chargement de modèle de la boutique n'est effectué pendant une partie. Roblox
doit néanmoins charger les maillages référencés par les MeshParts.

`LibraryVisuals.luau` garde ces décors ancrés, sans collision, sans contact et
hors des raycasts. Les anciennes surfaces de marche, le déclencheur Bounce,
les prix, les améliorations et les dégâts restent gérés par le code du jeu.
